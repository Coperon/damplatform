**2026-07-24 — Permanent tenant deletion (Stage 113).** Closes the gap flagged since Stage 99: no way to delete a tenant meant a mistyped or defunct one (the stray "Activity Scope Test Co") was permanent. FK audit first: `access_log.tenant_id` is `SET NULL` and stays untouched — that's the whole point, audit history survives; `invitations`/`tenant_collection_access`/`metadata_fields`/`tenant_role_permissions` all `CASCADE` off `tenants.id`, so deleting the tenant row alone handles most of the required cleanup; `users.tenant_id` is `NO ACTION`, so the tenant's users are explicitly deleted first, in the same transaction. "The tenant's collections" is defined precisely: a collection is exclusive only if no ancestor-or-self in its chain carries a grant for any other tenant, computed with one recursive CTE that walks every collection to its root and groups the tenant ids found in each chain — a chain with only the target tenant is exclusive and gets deleted; one with the target plus another tenant is shared and survives untouched, losing only the target's own grant. A resource is exclusive only if every collection it belongs to is in the exclusive set — one surviving membership keeps it. The subtlety this stage exists to get right: `collections.parent_id` is `ON DELETE CASCADE` and knows nothing about grants, so deleting an exclusive collection would blindly cascade-delete a *shared* collection nested beneath it — fixed by detaching (`parent_id = NULL`) any shared collection whose direct parent is about to be deleted, in a single non-recursive pass (provably sufficient, since everything beneath a shared collection is shared too). MinIO cleanup runs only after the transaction commits, one object at a time, failures logged and skipped rather than fatal. Logs `tenant_delete` to `access_log` with the deleted tenant's id/name and every count in metadata (`tenantId: null`, the actor's own — always null for a super admin — same "describe the gone target from metadata" shape as `user_delete`), added to the activity feed's whitelist/icon/phrasing.
